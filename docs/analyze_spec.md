# 图表抽象重构与 --analyze 交互分析功能规格

> 状态：已实现（2026-10-17）；2026-10-28 扩展为九视图
> 日期：2026-10-17（初版）、2026-10-28（四视图扩展 + 采集端追加写入）
> 涉及文件：`modian_tracker.py`（已修改）、`charts.py`（已新增，约 2040 行）

## 1. 背景与目标

`modian_tracker.py` 中的 `plot_trends()`（约 320 行）承担了数据加载、基础绘图与交互逻辑，无法扩展。本任务：

1. 新增 `--analyze` 参数，提供基于 matplotlib 交互式 widgets 的数据分析窗口
2. 分析窗口的基础绘图复用 `--plot` 的渲染
3. 将绘图部分抽象为类，移入独立源文件 `charts.py`，类关系按功能复用设计：`BaseChart -> PlotChart`、`BaseChart -> AnalyzeChart`

## 2. 设计

### 2.1 类结构（单文件 charts.py）

```
charts.py
├── BaseChart          可复用的数据与渲染基础
│   ├── CSV 加载（utf-8-sig、时间戳解析、按时序排序、NaN 兜底）
│   ├── 中文字体 / rcParams 配置
│   ├── 基础渲染：档位堆积面积图（左轴，万人）+ 总人数折线（左轴）
│   │             + 总金额折线（右轴，百万元）+ 里程碑 L 形标注
│   ├── 图例对齐（列名 + 最新值，全角宽度补齐）
│   ├── 十字跟踪线 + 数据行 tooltip（blitting 双背景优化）
│   ├── 背景失效/重建机制（mark_dirty，供缩放/平移/resize/widget 重绘复用）
│   └── 分析助手（daily_totals / flow_buckets / void_rates / marginal_share
│                 / cumulative_share / rhythm_matrix / finale_forecast）
│
├── PlotChart(BaseChart)      --plot：渲染后直接 show，输出与现状逐像素一致
│
└── AnalyzeChart(BaseChart)   --analyze：widgets + 9 视图 + 实时更新
    ├── widget 布局（fig.add_axes 预留控件区）
    ├── 视图注册与切换（RadioButtons）
    ├── 控件状态管理（时间窗口 / 聚合粒度 / 档位显隐）
    └── CSV mtime 轮询实时刷新
```

`modian_tracker.py` 仅保留：抓取、CSV 写入、循环采集、CLI 分发（`--plot` / `--analyze` 分支内按需 lazy import `charts`）。

### 2.2 AnalyzeChart 九个视图

| 视图 | 回答的问题 | 图表形式 |
|---|---|---|
| 基础趋势 | 总体走势 | 复用 BaseChart 渲染（与 --plot 一致） |
| 增速分析 | 众筹热度何时爆发/衰减 | 上下双子图共享时间轴：上=人数增速(人/时)、下=金额增速(元/时)；不用双轴 |
| 档位结构占比 | 档位结构如何迁移 | 主图：100% 堆积面积图（沿用基础图配色）；副图：时刻滑块选定的环形图快照（档位顺序固定 Lv1~Lv9、无偿支持，百分比标注，极小档位以标注数字兜底） |
| 客单价指标 | 新用户在选择哪个档位 | 累计客单价主线（总金额÷总人数）+ 窗口边际客单价副线（Δ金额/Δ人数）+ 9 条档位价格参考线（直接标注价格） |
| 里程碑节奏 | 筹款加速还是减速 | 每个百万级里程碑耗时的条形图（千万级视觉加重、直接标注耗时）+ 累计金额曲线叠加 |
| 净流拆解 | 钱是净流入还是被回吐抵消 | 上：毛增 / 回吐 / 净增（按聚合粒度，回吐画负值）；下：各档回吐率横条（回吐 ÷ 毛增） |
| 边际结构 | 新增的钱进了哪些档位 | 上：边际份额 100% 堆积（只含正向增量）；下：各档累计份额与窗口边际份额并列横条 |
| 日内节律 | 一天里什么时候下单 | 上：日 × 时热力图（按日归一，缺采灰块）；下：小时均值柱状图，标注峰值与负值小时 |
| 终局与阶段 | 还能筹多少、何时过下一关口 | 上：日增金额柱 + 3 日均线 + 阶段背景带与阶段日均；下：累计曲线 + 等差/指数两条外推包络 + 截止竖线 + 下一整百万关口 ETA |

### 2.3 交互控件（matplotlib 原生 widgets）

| 控件 | 作用 | 影响范围 |
|---|---|---|
| RadioButtons | 视图切换（9 选 1） | 全局 |
| Slider | 时间窗口选择 | 基础趋势 / 增速 / 占比主图 / 客单价 / 净流 / 边际 / 节律 / 终局 |
| Slider | 快照时刻选择 | 占比视图环形图 |
| CheckButtons | 档位系列显隐 | 基础趋势 / 占比视图 / 净流 / 边际 |
| RadioButtons | 聚合粒度（原始 / 10 分钟 / 小时） | 增速 / 客单价 / 净流 / 边际（即平滑手段） |
| Button | 重置（恢复默认状态，交互逃生通道） | 全局 |

- 十字跟踪线 + tooltip 保留于所有时序视图，tooltip 内容随视图自适应
- widget 触发的重绘复用 `mark_dirty` 背景失效机制
- 视图选择器扩到 9 项后矩形抬高到 `(0.015, 0.60, 0.145, 0.285)`、字号降为 8，避免与聚合粒度面板重叠
- 上下子图分属不同坐标系（上=时间轴、下=分类轴）时使用 `stack_gap()`，比 `panel_gap()` 多留 0.045 图高，给上子图刻度标签与下子图标题让位

### 2.4 实时更新

- 定时器轮询 `data.csv` mtime（默认 60s，与采集间隔一致）
- 检测到变化：重载数据 → 保留当前控件状态 → 重绘当前视图
- 可与采集循环并行运行（边采边分析）
- 采集端已改为 O(1) 追加写入：每次采样只读表头行与末 2 字节、只写 1 行（约 100 字节），不再全量重写 2.9MB；mtime 轮询语义不变，重载仍是全量解析

## 3. 约束

### 3.1 行为约束
- **--plot 输出与现状完全一致**（纯结构重构，零视觉变化，可回归对比）
- `--analyze` 默认视图为基础趋势图

### 3.2 项目既有规范（必须遵守）
- 采集功能与 matplotlib 库解耦：`modian_tracker.py` 顶层不得导入 matplotlib / charts，仅在 `--plot` / `--analyze` 分支内 lazy import
- 无偿支持为独立档位，不使用 Lv 编号；堆积顺序自下而上 Lv1~Lv9、无偿支持
- 总人数左轴、总金额右轴
- CSV 为 utf-8-sig 编码；人数类数据为整数（无 .0 后缀）
- 档位列名格式 `LvX（￥xx）`

### 3.3 数据兜底与口径
- 早期行总人数/总金额为空 → 按 NaN 处理并跳过
- 占比视图分母为档位列之和（页面总人数与档位和不必然一致）
- 时间戳解析失败的行跳过（与现状一致）
- 毛增 / 回吐：先在原始相邻采样上判定正、负增量，再按聚合桶分别求和（桶首尾差会抵消桶内「先退后买」）；相邻采样间隔超过 5 分钟的断采步长直接跳过，避免把 13 小时增量塞进单个桶
- 日增量 = 当日最后一个累计值 − 上一日最后一个累计值；缺整日跳过；当日末采早于 23:00 记为不完整，不参与终局拟合（日内断采不影响跨日末值差）
- 日内节律按日归一（该小时增量 ÷ 当日增量之和），缺采用掩码而非 0，不参与小时均值；分母为 0 的日整行留空
- 边际结构分母只含正向增量；累计份额分母为档位人数总和
- 终局外推：最近 7 个完整自然日，日增均值做等差外推 + 日增对数线性拟合（指数衰减），两轨之间填充包络；数据末行晚于截止时刻时停止外推
- 阶段切分为模块常量（P1 起势 10-05~10-08、P2 退坡 10-08~10-15、P3 二次脉冲 10-15~10-18、P4 断崖 10-18~10-23、P5 长尾 10-23~11-16），与本文阶段叙事同步维护

### 3.4 技术约束
- 仅使用 matplotlib 原生能力（widgets / 事件 / blitting），不引入新依赖
- Python 3.11，项目 `.venv` 环境

技术备注：

1. 净流视图的毛增/回吐按 10 分钟桶聚合并画成面积与折线而非柱状：全期 3,300+ 桶时柱宽不足 1px。
2. 跨断采步长（>5 分钟）在净流、回吐率、边际份额里一律跳过；否则 10-21 22:46 → 10-22 11:46 的 13 小时增量会落成单桶数万元尖峰。
3. 终局等差外推取 7 日均值，而不是对 7 个点做 OLS：日增量本身在下滑，OLS 斜率会把截止前的日增推成负数，累计曲线随之下折（实测 35.39M，低于当时累计 38.7M）。
4. 九视图共用同一份内存数据与时间窗口；切换视图不重新解析 CSV。

## 5. 成品目标（验收标准）

1. `python modian_tracker.py --plot` 生成的图表与重构前完全一致
2. `python modian_tracker.py --analyze` 打开交互窗口：9 个视图可切换，时间窗口/聚合粒度/档位显隐/重置控件均生效
3. 占比视图环形图随时刻滑块动态更新；增速/客单价/净流/边际视图随聚合粒度切换变化
4. 采集进行中时，`--analyze` 窗口每 60s 内自动反映新数据
5. 无参运行（采集模式）的进程不加载 matplotlib（满足采集解耦约束）
6. 绘图代码全部位于 `charts.py`，`modian_tracker.py` 无绘图逻辑残留
