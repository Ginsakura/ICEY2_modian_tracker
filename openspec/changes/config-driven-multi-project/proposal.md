# 配置驱动的多项目追踪器

## Why

当前追踪器只服务一个众筹项目：追踪 URL、CSV 文件名、日志文件、抓取间隔、截止时间、阶段切分、时间轴左边界与百万关口步长全部写死在代码和脚本里。新增第二个项目（《与中草药娘的日常》，160539）时，只能复制一份代码或逐处修改常量；而两个项目的档位数（9 对 5）、档位价格、标题与截止时间都不同，硬编码无法同时容纳。

ICEY2 将于 2026-11-15 23:59 收官，之后需要把注意力转到新项目，同时保留历史数据与现有分析视图。现在把采集与图表改成配置驱动，可以让“盯下一个项目”变成在配置里加一条记录，而不是再改一轮代码。

## What Changes

- 新增 `trackers.json`：全局默认值 + 每个项目的 `url`、`data_file`、`interval`、`enabled`、可选的采集窗口 `collect_from`/`collect_until`，以及可选的 `campaign`（`deadline`、`start`、`phases`、`milestone_step`）。项目名必须匹配 `^[A-Za-z0-9_]{1,32}$`，且大小写不敏感唯一。采集窗口使用本地时间，截止时刻为开区间；`campaign.deadline` 只负责图表外推，不承担采集起止语义。
- 采集端改为配置驱动：单进程多线程，每个项目一个采集线程，另有一个全局 git 同步线程；每个项目写自己的 CSV，日志带项目标签；提供 `--once` 试运行；配置修改后重启生效。
- 新增交互式配置工具 `manage.py`：纯标准 `input()` 交互菜单，另提供 `list/check/preview/add/disable` 非交互子命令；保存前实际抓取一次页面并预览解析结果；配置采用原子写入。
- 解析器读取档位标题 `.back-sub-title`，列名改为 `Lv.{n} {标题}（￥{price}）`：去掉标题开头的 `LV{n}` 前缀，去掉后为空则省略标题；价格作为列的唯一标识，标题变更不改旧列名。
- 图表从项目配置读取 CSV 路径、截止时间、时间轴起点与阶段；里程碑步长默认按当前最大总金额自适应（目标约 40 个关口，`max/40` 取最接近的 `{1,2,2.5,5}×10^n`），可用 `campaign.milestone_step` 显式覆盖；金额单位随量级在 元/万元/百万元 之间切换，ICEY2 的 27M/30M/10M 文本保持不变。`phases` 改为可选，未配置时不绘制灰带与阶段日均标注；任意档位数均可正常绘制。
- **BREAKING**：采集入口不再支持“无配置直接运行并固定写 data.csv”的用法，必须提供 `trackers.json`；`run` / `run.ps1` 不再接受 interval 参数，抓取间隔完全由配置决定；旧版单项目 API 与临时桥接/迁移脚本全部移除。
- 上线：ICEY2 数据最终位于 `data/icey2.csv`，LINGLAN 位于 `data/linglan.csv`。手机端停止旧进程后，手动把现有 `data.csv` 移动并重命名为 `data/icey2.csv`，再启动统一采集器；已有旧表头无需迁移，追加器按价格绑定旧列并保持原样，新文件才使用带标题的列名。

## Capabilities

### New Capabilities

- `tracker-config`: 配置文件结构、项目标识与校验规则、交互式与非交互式配置工具、保存前预览、原子写入，以及多项目启动入口。
- `multi-project-collect`: 单进程多线程采集调度、逐项目数据文件与日志标签、逐项目抓取间隔、git 同步线程与优雅退出。

### Modified Capabilities

- `csv-append-write`: 列名格式加入档位标题；列身份从 Lv 序号改为价格；同一采集进程内多个项目各自维护追加与表头重写状态。
- `analysis-view-suite`: 截止时间、时间轴起点、阶段与里程碑步长改为项目配置；phases 未配置时不绘制阶段标注；档位按价格识别，支持任意档位数。

## Impact

- 代码：`modian_tracker.py`（拆分配置加载与采集线程）、`charts.py`（常量注入与列解析）、`shared_logger.py`（项目标签）、`run`、`run.ps1`，新增 `manage.py` 与 `trackers.json`。`sync_data.py` 的线程嵌入方式保持不变。
- 数据：`data.csv` 移动为 `data/icey2.csv`；新增 `data/linglan.csv`；旧表头保持原样，日志格式增加项目字段。
- 流程：启动、停止、重启命令与配置生效方式发生变化；新项目接入流程变为“编辑配置 → 预览 → 重启”。
- 依赖：不新增第三方依赖，配置解析使用标准库 `json`。
