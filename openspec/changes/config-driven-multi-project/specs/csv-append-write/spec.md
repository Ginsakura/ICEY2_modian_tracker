# csv-append-write Specification

## MODIFIED Requirements

### Requirement: 常规采样 MUST 采用单行追加

当某个项目的 data_file 已存在且表头包含本次采样的全部列时，采集端 MUST 只读取该文件表头行，并以一次追加写入完成本次采样；MUST NOT 读取或重写历史数据行，MUST NOT 因为其他项目的写入而重写本文件。多个项目并发追加时 MUST 各自只操作自己的文件。

#### Scenario: 表头一致时追加一条采样
- **WHEN** data_file 存在、表头含本次采样全部列，追加一行采样
- **THEN** 文件行数恰好增加 1，历史行的字节内容保持不变
- **AND** 本次写入从文件读取的字节数不超过表头行长度加 2 字节

#### Scenario: 成本不随历史规模增长
- **WHEN** 同一个文件分别有 3 万行和 30 万行时各追加一行
- **THEN** 两次追加的读取字节数相同，且都不包含历史数据行

#### Scenario: 多项目并发追加
- **WHEN** 两个项目在同一时刻各追加一行
- **THEN** 每个文件只增加自己的那一行，两个文件互不影响

### Requirement: 表头演进 MUST 通过一次性原子重写完成

当采样包含表头中不存在的列时，采集端 MUST 先按价格把本次采样的付费档位解析到已有列：价格相同即视为同一档位，即使该档位的标题已经变化；只有价格在表头中不存在时才追加新列，列名使用本次采样生成的新名称。若同一价格在表头中出现多次，MUST 按出现顺序把本次采样中的同价档位依次绑定到这些列，列数不足时才追加。重写时 MUST 先构造完整表头与历史行的补齐结果，写入同目录临时文件，再用原子替换覆盖当前项目的 data_file；MUST NOT 直接截断原文件。重写完成后，后续采样 MUST 回到追加路径。

#### Scenario: 新增档位列
- **WHEN** 本次采样出现历史表头中没有的档位价格
- **THEN** 表头末尾追加该列，全部历史行在该列补空字符串
- **AND** 文件通过临时文件原子替换生成，下一次采样恢复单行追加

#### Scenario: 标题变化沿用旧列
- **WHEN** 某档位价格已存在，但页面上该档位的标题被作者修改
- **THEN** 本次采样写入原有列，表头不新增列，列名保持修改前的标题

#### Scenario: 同价多档
- **WHEN** 页面出现两个价格相同的付费档位，表头中已有两个同价列
- **THEN** 按页面出现顺序绑定到这两个列，不新增列

#### Scenario: 重写中途失败
- **WHEN** 临时文件写入或替换失败
- **THEN** 原 data_file 内容保持不变，并记录错误日志

## ADDED Requirements

### Requirement: 档位列名 MUST 包含标题与价格

付费档位的列名 MUST 采用 Lv.{n} {标题}（￥{价格}） 格式，其中 n 为该档位在页面付费档位中的出现顺序，从 1 开始；标题 MUST 取自该档位卡片的 .back-sub-title；写入前 MUST 去掉标题开头的 LV{n} 前缀以及紧随其后的空格或分隔符；去掉后为空时 MUST 省略标题，只保留 Lv.{n}（￥{价格}）。括号 MUST 使用全角括号，货币符号 MUST 使用全角￥；价格 MUST 与页面展示的字符串一致，MUST NOT 重新格式化。免费档的列名 MUST 固定为 无偿支持。

#### Scenario: 标题包含 LV 前缀
- **WHEN** 页面标题为 LV1 早鸟 数字版，价格为 42
- **THEN** 列名为 Lv.1 早鸟 数字版（￥42）

#### Scenario: 标题只有编号
- **WHEN** 页面标题为 LV3，价格为 88
- **THEN** 列名为 Lv.3（￥88）

#### Scenario: 标题为普通文字
- **WHEN** 页面标题为 吧唧也想贴贴，价格为 38
- **THEN** 列名为 Lv.3 吧唧也想贴贴（￥38）

#### Scenario: 免费档
- **WHEN** 页面第一个档位是无需回报的无偿支持
- **THEN** 该列列名为 无偿支持

### Requirement: 档位价格 MUST 可从列名末端解析

分析端 MUST 从列名末尾的全角括号中解析价格，即匹配 （￥数字） 且位于列名结尾；MUST 接受整数与小数价格，MUST NOT 把标题中出现的货币符号或数字误认为价格。列名不含末端价格时 MUST 视为无法计价，并按金额口径规则跳过该采样行。

#### Scenario: 标题中含价格字样
- **WHEN** 列名为 Lv.2 早鸟价￥19.9 限定（￥45.6）
- **THEN** 解析出的价格为 45.6

#### Scenario: 列名缺少末端价格
- **WHEN** 某付费列列名为 Lv.2 特别档
- **THEN** 该列不参与金额计算，并计入跳过提示
